# DESIGN.md — Forge 工作台(v0.5)

## Direction & Layout
克制、精致、有辨识度的开发工具。主线是 **需求输入 → 执行进度 → 应用预览**:左侧栏(380px)从上到下为「当前任务状态卡 + 阶段进度」「对话」「记忆(可折叠)」「输入框 + Plan/Build 选择」;右侧主区为「计划 / 预览 / 代码」标签页。Plan 阶段默认显示计划页,方便阅读和审阅;Build 完成后默认显示预览页。左栏在桌面端可收起,给预览留出空间。
- 断点:`<1024px` 上下堆叠,左栏最高 55dvh 且可滚动,输入框固定在栏底始终可用;`≥1024px` 左右两栏。
- 不做装饰卡片、大面积渐变、无意义动画;不加统计、团队、账单、部署等未实现的入口。

## Tokens(`src/index.css` :root)
| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | #F7F7F5 | 主背景 |
| `--panel` | #FFFFFF | 面板背景 |
| `--text` | #111111 | 主文字 |
| `--text-2` | #6B6B6B | 次级文字 |
| `--line` | #E8E8E5 | 1px 细边框 |
| `--accent` | #5B5BD6 | 唯一品牌强调色(主按钮、选中态、焦点环) |
| `--accent-hover` | #4F46E5 | 强调按钮 hover |
| `--success` | #16A36A | 成功 |
| `--danger` | #B42318 | 错误(仅用于失败文本与边框) |

字体:界面 IBM Plex Sans,代码/日志 JetBrains Mono。标题 15px/600,正文 14px/22px,次级 12–13px,小节标题 12px 大写。间距 4/8/12/16/20;圆角 6px(控件)/8px(面板)。

## States(不能只靠颜色区分,每种状态都有图标和文字)
- 空:虚线圆图标 +「暂无任务」+ 下一步说明。
- 等待:时钟图标 +「排队等待」。
- 运行:旋转图标 +「执行中 · 当前步骤」;阶段列表逐项显示 待开始 / 进行中 / 完成 / 失败。
- 失败:警告图标 +「本轮失败:简短原因」+ 最后执行的工具与耗时 + 下一步 + 恢复任务 / 新建任务;原始错误折叠显示。
- 成功:勾选图标 +「已完成」,预览页加载 iframe。
- 历史失败放在折叠区「历史失败(N 轮,不属于当前任务)」中,并标注轮次;对话中的旧消息也标注轮次。

## Patterns
- 主按钮 `.btn-primary`(白字配 --accent,hover 时为 --accent-hover);次按钮 `.btn-ghost`(透明底配细边框,hover 时边框变为 --accent)。
- Plan/Build 使用 radiogroup,选中项带「●」和强调色边框;旁边注明「仅影响下一次提交」。
- 计划页:版本号与状态徽标(待审阅 / 已批准 / 已被新版本替代)、版本切换(旧版本只读)、问题(推荐选项 + 自由输入)、「还有什么其他补充?(可跳过)」、底部固定「提交意见,修改计划」与「批准 vN 并构建」。
- 焦点环 2px --accent;图标按钮都带 aria-label;遵守 `prefers-reduced-motion`。
